# 🚦 CityGuard

A smart hazard detection and public safety system . CityGuard aims to improve public safety by identifying potential hazards and providing timely alerts through a simple and intuitive interface.

## 🏆 About the Project

CityGuard was designed and built within **24 hours** as part of a hackathon challenge. The project demonstrates rapid problem-solving, teamwork, and the ability to deliver a functional solution under strict time constraints.

## ✨ Features

- 🚨 Hazard detection system
- 📢 Public safety alerts
- 💻 User-friendly interface
- ⚡ Fast and responsive design
- 📱 Cross-device compatibility

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

```bash
git clone https://github.com/Rishikesh777/CityGuard.git
```

Open `index.html` in your browser.

No installation or dependencies required.
